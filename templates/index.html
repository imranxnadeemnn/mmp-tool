Download Mac Result Viewer
Setup after download:
1. Unzip `macos-result-viewer.zip`
2. Double-click `Install MMP Result Viewer.command`
3. If macOS blocks it, right-click the file and choose `Open`, or allow it in `System Settings -> Privacy & Security`
4. Enter your Redash API key when prompted
5. Stay connected to office VPN when checking results
6. If needed, remove the macOS quarantine flag in Terminal:
`xattr -d com.apple.quarantine "Install MMP Result Viewer.command"`
